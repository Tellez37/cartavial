          Integración Cloud · Sin servidores costosos
          
Conectar Google Sheets y Google Forms

        

        
      


      

        CartaVial ya funciona de inmediato con la base de datos local/demo. Para conectarlo en vivo a tu hoja de cálculo de Google Sheets, pega el link de tu hoja pública aquí:
      


      

        

          
          
          
            En Google Sheets haz clic en Compartir → Cualquier persona con el enlace (Lector) o Archivo → Compartir → Publicar en la web y pega el link arriba. CartaVial lo transforma automáticamente a JSON mediante el endpoint público /gviz/tq?tqx=out:json.
          
        


        

          
          
          
            Si pegas el link de tu Google Form, los usuarios tendrán un enlace directo para abrirlo, o si pegas la URL de un Web App de Google Apps Script se guardará automáticamente cada reporte en tu Google Sheet.
